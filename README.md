This repository contains some of the main features of Freddy, specifically software-related aspects mentioned throughout the report. 

Custom Parrot Voice - contains Freddy's custom trained voice model
Final CAD STLs - contains all CAD STL files for Freddy
Freddy Main Code - contains the main Freddy script that it runs from
General Proj Docs - contains past submitted Porj-related documents like Proposals, Powerpoints, etc
Loggeed Test Data - contains all the logged data when testing Freddy
Porcupine - contains the custom 'Hey Freddy' wake-word model 
Servos - contains the servo calibration code
TextyMcSpeechy Linux Screenshots - contains all the Linux code used for TextyMcSpeechy to generate the voice
